AgentTerm 0.10.0 speaks protocol version 28: both the Mac and the iPhone have to be 0.10, and so does the host. After updating the Mac app, restart the host when the app offers to, then update the iPhone app.

## New

- **The Inbox.** What needs you, the most pressing first: the agents that wait for an answer, what stopped, then the agents that are done and were not looked at since. On the Mac it is a place of its own at the left edge, with how many items it holds; on the iPhone and the iPad it is at the top of the sessions' list. A done item goes when its session is looked at on any device, or when it is dismissed.
- **What a turn came to.** An agent that is done shows what it was asked, what it answered, the commands it ran with their exit codes, and the files that changed while it worked. From there: Open Diff, Continue with the next instruction, or Hand Off. Settings > Git > "Show what each turn came to" turns it off.
- **Tabs that hold what they gather** (Mac). The strip has a tab for each running agent, and one each for your shells, pages, diffs and files of the project, saying how many it holds. A row under it holds what the tab in front holds: there each is picked, opened and closed. An agent's tab keeps its area, the agent on the left, its page on the right, its shell under both, and two buttons in the row hide and show the page and the shell. The list at the left, and the lists on the iPhone and the iPad, are grouped the same way.
- **An agent typed in a shell is an agent.** `claude`, `codex`, `copilot` or `agy` typed by hand in a shell of AgentTerm is found, and while it runs the shell is its session: its usage, its state, the Inbox, its own shells and pages.
- **The thinking level** of an agent is shown next to its model, in the agent's own words, on the Mac and the iPhone.
- **A right-click menu in pages** (Mac), as Chrome's: Open Link in New Tab and Copy Link Address on a link; Back, Forward and Reload on the page; Inspect always.
- **Chrome extensions** can be installed from the Chrome Web Store in the Mac app's browser. A window Chrome opens by itself is held back and said in the Browser tab, with Open in Chrome Window to show it.
- **Who has a session.** While another device decides a session's size, both apps name it: "In use on iPad · 80×24".

## Changed

- **Hooks and MCP are set up by you, once.** AgentTerm now starts an agent as you would, with nothing of its own on its command line. What it needs of each agent is in the agent's own configuration, for your user and every folder, once you press Install in the new Settings > Hooks & MCP. Each part is added with the agent's own command when it has one: AgentTerm's MCP server with `claude mcp add`, `codex mcp add`, `copilot mcp add` or `agy mcp add`. What no agent has a command for, its hooks and Claude Code's status line, is added by AgentTerm's own, `agenttermd setup <agent>`. The pane shows every command, to run in a terminal instead, and the ones that take them out; `agenttermd setup status` says what each agent has. A screen shows each time the app opens while an installed agent is not set up, and each agent's session has a mark of whether its hooks and its server were heard. Until an agent is set up, AgentTerm does not know what it is doing, and the agent has no shells or pages of AgentTerm's. Outside AgentTerm, an agent that is set up works as before.
- **Codex's shared server is turned off by Install.** Codex 0.169 runs its sessions through one background server they share, through which AgentTerm cannot tell one session from another. Install turns that off for all of Codex, with Codex's own command (`codex features disable daemon_auto_start`), and Remove turns it on again. If such a server is still running, Settings > Hooks & MCP says "Shared server on" and what to do: quit Codex's sessions, then `codex app-server daemon stop`. Until then a Codex session has no shells or pages of AgentTerm's and its state is not shown.
- Tab groups and their colours are gone, on the iPhone and the iPad too. On the iPhone an agent's session is pinned and moved; a shell no longer is.
- The fetch AgentTerm makes by itself every five minutes no longer holds Fetch, Pull, Push and the rest while it runs. What you ask for meanwhile is done when it is over.

## Fixed

- Typing into a large file no longer holds the window up at each key: of twenty letters typed into a file of 5 MB, 18 to 21 did, now 1 to 3.
- A line with more than twelve tabs was broken into several lines in the editor.
- A push or a pull asked for just as AgentTerm began its own fetch was thrown away without a word.
- Mac: Show As on a page's bar, pressed again right after the first device was picked, showed a list that could not be used, and then took two presses to open.
- Mac: a host left running from an earlier build is pointed out, whatever the protocol.
- Mac: the list at the left holds your pages under one Browser row, as the strip does.
- A build from source made without Chromium (`scripts/fetch-cef.sh` not run) links again.

## Known

- Antigravity asks whether to allow each of AgentTerm's tools the first time it calls one ("Allow calling this tool?"). Until that is answered its session waits, and as Antigravity does not say that it waits, AgentTerm does not show it as waiting (#141).
- While a right-click menu is open in a page, that page is not read again when it was asked to reload, until the menu closes (#139).
- Chromium's own processes (GPU, network and storage, about 80 MB together) still run from the first page opened until the app quits (#117).
- A page shown live on the iPhone and the iPad is softer than it is on the Mac (#107).
