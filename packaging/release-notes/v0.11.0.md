AgentTerm 0.11.0 speaks protocol version 31: both the Mac and the iPhone have to be 0.11, and so does the host. After updating the Mac app, restart the host when the app offers to, then update the iPhone app.

## New

- **A Mac showing another Mac has its browser.** That Mac's pages, its agents' too, are shown from the pictures it sends, as on the iPhone, and used from here: a click, scrolling, the keys, ⌘V, the address, back, forward, reload, a new page. Picking an element, Show As, finding, zooming and the developer tools stay on the Mac whose page it is.
- **One Browser for your pages** (Mac). A page you open belongs to no folder: one Browser, in the strip of every folder and above the folders in the list. An agent's pages stay with it.
- **Continue a conversation in a new worktree.** "+" of the worktree bar can begin by continuing one of the folder's conversations: it is handed off into the new worktree, and the agent is told to work there only.
- **The iPhone's Settings has the Mac's Hooks & MCP, Shell, Browser and Agents**: Install and Remove for each agent, the shell of new sessions, the browser's profiles (Clear Data and Delete asked first), and the words each agent is told. A Mac showing another Mac sets that Mac's agents up the same way.
- **Files into a terminal** (Mac). A file dropped on a terminal, or copied in the Finder and pasted, has its path typed in. ⌘V with a picture on the clipboard, a screenshot say, sends Control V, with which Claude Code takes the picture itself.
- **A submodule's own commit box** (Mac), with Write, as the folder's and the iPhone's.
- **The memory in gigabytes** on the Mac's line of figures, as on the iPhone.

## Changed

- **Closing a tab closes all it holds**, asked first: the Shells, Diffs, Files and Browser tabs all their items, an agent's tab the agent with the shells and pages it opened, on the Mac and the iPhone alike. An agent that ends by itself still leaves its shells and pages to you.
- An agent's first item in its row is "Agent", never the name its tab already says.
- The list at the left marks the row you picked, a folder or a group, not the item in front; files and diffs have a menu: Close, Open File, Show in Finder, Copy Path.
- An element picked in an agent's page goes to that agent; in a page of yours, any running agent, the folder's first.
- Install stops Codex's shared background server when it runs, with Codex's own command (`codex app-server daemon stop`); Codex sessions started through it before may stop. Install for All is at the top of the list.
- Each device says what it is: an iPhone's or an iPad's icon where a session is used on it, none for a Mac.
- The schedule's larger prompt editor is gone, on both apps.

## Fixed

- An agent typing into an editor that keeps its own state, as X's post box, left it showing nothing, and a second time added to the text instead of replacing it.
- A sign-in in a popup, as "Sign in with Google" on X, did not come back to the page: the popup lost its opener. A page that closes itself now closes its tab.
- The agents are told to load AgentTerm's shells' tools before their first command, rather than use their own.

## Known

- A Mac showing another Mac's page cannot hover, right-click, drag or select text in it yet (#147).
- Chromium's own processes (GPU, network and storage, about 80 MB together) still run from the first page opened until the app quits (#117).
