AgentTerm for iPhone is a remote for the coding agents running on your Mac. This version works with AgentTerm 0.11 on the Mac only: https://github.com/manhpham90vn/AgentTerm/releases

New in 0.11.0

- Settings has the Mac's Hooks & MCP, Shell, Browser and Agents: set each agent up on the Mac from here, change the shell of new sessions, the browser's profiles, and the words each agent is told.
- Ending an agent ends the shells and pages it opened too, asked first.
- A new worktree can begin by continuing one of the folder's conversations, handed off into it.
- Your pages of the Mac's browser belong to no folder: they are under "Browser on the Mac".
- A session another device has shows that device's own icon, an iPhone's or an iPad's, none for a Mac.

Please try

1. Update the Mac app to 0.11.0 first and restart its host when the app offers to.
2. Settings > Hooks & MCP: Install an agent from the iPhone, and see its parts turn to added.
3. Start an agent that opens a shell, then end the agent from the iPhone: the question names its shell, and both end.
4. A folder's worktree bar: "+", Begin: Continue a Conversation, Create.
