AgentTerm 0.12.0 speaks protocol version 32: both the Mac and the iPhone have to be 0.12, and so does the host. After updating the Mac app, restart the host when the app offers to, then update the iPhone app.

## New

- **Notifications on every device, through Apple while the iPhone app is asleep.** An agent that asks something, needs your permission or is done, and every failure that stopped work, is told once to every device, the Mac's own app included, saying whether someone is at the Mac. While the iPhone app is asleep, the notice comes through Apple's push: the Mac encrypts it for that one device, a relay of AgentTerm's passes it on, and only the iPhone can read it. Handled on one device (answered, opened, dismissed, or the agent moving on), it is gone from all of them.
- **The Inbox is a history**, on the Mac and the iPhone: the notices of 30 days, each device its own; delete one, the read ones or all. An agent that waits for you stays until it is answered.
- **The Live Activity shows the Mac's state at all times**, counted by kind (working, waiting, done, failed), kept true by Apple's push while the app is asleep, and started by it when an agent begins working.
- **The Markdown preview is laid out as GitHub shows it**, as a web page: tables, task lists, struck-through text, links found in the text, coloured code and Mermaid diagrams. A long document opens as fast as a short one and scrolls without holding the window up (`TESTING.md` of AgentTerm's own: 1.7 s before, about 30 ms now). HTML written in the file is not run.
- **⌥⌘1–9 picks an item of the row** of the tab in front (Mac), its numbers shown while ⌥ and ⌘ are held; the file, diff, page or shell picked gets the keyboard.
- **The session mark's popover has three rows**, Hooks, MCP and System Prompt, each with its state: checking, heard or connected, not, given, disabled or unverified, following the session while it is open.

## Changed

- iOS's own banner shows a notice with the app open too; notifications are asked for once a Mac is paired. Failures show in a banner at the top on the iPhone, as on the Mac.
- macOS notifications while the app is behind, with a switch in Settings.
- The same words and buttons on both apps for what is going on: connecting, not reachable, another release, "Use This Size".
- The close buttons of the tab strip and the list are 18-point controls, easier to hit (Mac).

## Fixed

- A new worktree offered conversations of other folders: now only the folder's and its worktrees' own.
- An element a page replaces as it is picked reached the agent with empty styles: it is read first, or said to be gone.
- A new folder opened with the Browser selected instead of its own workspace (Mac).
- The iPhone's Push button broke its words over lines when it counted commits.

## Known

- Opening any document's tab still holds the window up for a moment, 20 to 80 ms on the Mac (#178).
- A Mac showing another Mac's page cannot hover, right-click, drag or select text in it yet (#147).
