AgentTerm for iPhone is a remote for the coding agents running on your Mac. This version works with AgentTerm 0.12 on the Mac only: https://github.com/manhpham90vn/AgentTerm/releases

New in 0.12.0

- Notifications through Apple while the app is asleep: an agent that asks, needs permission or is done, and failures that stopped work. Handled on one device, gone from all.
- The Inbox is a history of 30 days: delete one, the read ones or all.
- The Live Activity shows the Mac's agents at all times, by kind, kept up to date while the app is asleep.
- Markdown files are shown as GitHub shows them, tables and diagrams included, fast whatever their length.

Please try

1. Update the Mac app to 0.12.0 first and restart its host when the app offers to; allow notifications on the iPhone when asked.
2. Start an agent, leave the app and lock the iPhone: a notification comes when it is done or asks something; answer it on the Mac and see it go from the iPhone.
3. With the app asleep, see the Live Activity follow the agents: working, then done.
4. Open a long Markdown file in a folder's Files.

What to tell me

A notification that did not come or came twice, a Live Activity that stayed at an old state, what was slow, and anything that read wrong.
