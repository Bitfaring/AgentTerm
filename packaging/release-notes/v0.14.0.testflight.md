AgentTerm for iPhone is a remote for the coding agents running on your Mac. This version works with AgentTerm 0.14 on the Mac only: https://github.com/manhpham90vn/AgentTerm/releases

New in 0.14.0

- Notifications come at once, time-sensitive, for an agent that asks, is done or stops asking, and for a failure; progress is not notified.
- The Live Activity changes at once when an agent starts or stops asking.
- While an agent asks, "Answer the Agent" opens a place to answer, and a prompt being written is kept.
- Worktrees are picked from a popup with search.
- The Inbox shows the end of an answer, three lines; an item opens whole, as Markdown or as text.
- A session's screen stays right while Claude Code works with subagents.

Please try

1. Update the Mac app to 0.14.0 first and restart its host when the app offers to.
2. Lock the iPhone and let an agent ask something: the notification comes at once, also during a Focus.
3. With the Live Activity showing, answer the agent on the Mac: within seconds it no longer says the agent is asking.
4. Start writing a prompt and let the agent ask meanwhile: answer it from "Answer the Agent", then send the prompt.
5. Open a session while Claude Code runs subagents and watch it draw.

What to tell me

A notification that came late, twice or not at all; a Live Activity that stayed at an old state; a prompt sent as an answer; a screen drawn wrong.
