AgentTerm for iPhone is a remote for the coding agents running on your Mac. This version works with AgentTerm 0.15 on the Mac only: https://github.com/Bitfaring/AgentTerm/releases

New in 0.15.0

- Touching a notification no longer closes the app (0.14.0 quit on some answers).
- A worktree being made is shown under its folder, with what is being done, until its session starts.
- Worktrees are named by their folder, with the branch checked out in each beside it.
- A session in a worktree says the branch checked out there now.

Please try

1. Update the Mac app to 0.15.0 first and restart its host when the app offers to.
2. Touch a notification of an agent that is done: the app opens on its session and stays open.
3. Start an agent in a new worktree of a folder with submodules: the row under the folder says what is being done until the session starts.
4. Check out another branch in that worktree on the Mac: the session's row says the new branch.

What to tell me

The app closing when a notification is touched; a worktree being made that shows nothing; a branch that is not the one checked out.
