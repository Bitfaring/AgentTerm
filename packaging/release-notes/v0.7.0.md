AgentTerm 0.7.0 speaks protocol version 15: both the Mac and the iPhone have to be 0.7, and so does the host. After updating the Mac app, restart the host when the app offers to, then update the iPhone app.

## New

- **Git, done in the app.** Branches: switch, make, rename and delete. The history of commits, with a graph of where branches part and meet; revert and cherry-pick. Fetch, pull by merge or rebase, and a forced push that names the commits it would overwrite. The stash. Amend and undo the last commit. Discard changes, or stage, unstage and discard a hunk or some of its lines (on the Mac). Merge and rebase conflicts resolved by a side or by hand. Submodules. On the iPhone: branches, the commits of any branch, revert, cherry-pick and discarding.
- **Worktrees made easy.** A bar of chips, the folder's branch and then each worktree with what is changed in it; a new one from a sheet; merge, pull request or throw away. On the iPhone too.
- **Search the folder's files.** Go to File… (⌘P) by name and Find in Files… (⌘⇧F) by text, on the Mac and the iPhone.
- **History.** Search what was said, or the titles only; group by agent or day and filter; read a conversation as a transcript, its Markdown rendered if you like, and copy anything said in it; pin, hide, and delete one, several picked, or every one on the Mac, after two questions.
- **Schedules.** Run Now and Stop; what each run did; runs that fail are said in the banner; every N minutes or hours, between two times, on certain dates; a worktree of its own for each run; Pause All. On the iPhone, Schedules is a tab of its own.
- **An agent that is not installed** shows in the Mac's header. Pressed, it says how its maker installs it, and types the command into a new shell for you to read and run.
- **One first-launch screen** for crash reports and usage statistics, with a switch for each.

## Changed

- Only the agent that opened a shell types into it; every agent can read them, and the rows say whose each one is.
- Each build installs its own MCP server, and an agent that cannot reach its host is told why at once; both apps show a banner until it is over.
- Answering an agent's question picks the choice in the agent's own list; on the iPhone a choice is a button of the notification.
- A notice hides once its session is opened, on any device. The Mac's banner opens out to all that the agent said.
- The Git tab says what its numbers count: files, lines, commits.
- The Mac's History list is wider, and a transcript's Pin, Hide and Delete are buttons in view.

## Fixed

- A `git commit` in a terminal no longer fails now and then with "Unable to create index.lock" while the app looks at the repository.
- A text file of 5 MB opens in about 30 ms instead of 5 s, and a diff of 20,000 lines scrolls without a stall.
- A forced push no longer overwrites commits that reached the remote after you looked.
- Schedules: two limit-reset schedules of one agent both run; a run whose agent never says it is done no longer holds its schedule up; a run whose folder is gone is not started; a run open when the host stops is closed.
- Stopping a command stops what it started too.
