AgentTerm for iPhone is a remote for the coding agents running on your Mac. This version needs AgentTerm 0.7 on the Mac, with its host restarted: https://github.com/Bitfaring/AgentTerm/releases

New in 0.7.0

- Git: switch, make, rename and delete branches; the commits of any branch; revert and cherry-pick; discard changes.
- Worktrees as chips above a folder's changes, with what is changed in each.
- Search a folder's files by name and by what is in them.
- History: search what was said or the titles only, filter, read a transcript (its Markdown rendered if you like), copy a message, pin, hide, and delete several at once.
- Schedules is a tab of its own: Run Now, Stop, and what each run did.
- Answer an agent's question with a choice, from the notification.

Please try

1. Update the Mac app to 0.7 first, and restart its host when the app offers to.
2. In a folder's Git tab: switch to another branch, open Commits, pick a commit and revert it.
3. History: search a word an agent said, then turn on Search Titles Only in the menu beside the field. Select two conversations and delete them.
4. Schedules: Run Now on a schedule, then open the run to see what it did.
5. Leave the app while an agent works on something that asks a question, and answer it with a choice from the notification.

What to tell me

What did not work, what was slow, and anything that read wrong.
