AgentTerm 0.8.0 speaks protocol version 22: both the Mac and the iPhone have to be 0.8, and so does the host. After updating the Mac app, restart the host when the app offers to, then update the iPhone app.

## New

- **A browser for you and your agents.** Chromium, built into the Mac app. An agent opens its own tabs, reads the page, clicks, types, fills forms, uploads its project's files, takes screenshots and reads the console and the network, through 22 `browser_` tools; it sees and uses only the tabs it opened. You can take a tab over and give it back, show a page as a phone or a tablet would, and open private tabs. With two profiles or more, the Browser button lets you pick one, and an agent asks you which in its conversation.
- **An agent's area.** An agent's shells and its page sit beside it in one pane on the Mac; move the keyboard between them (⌥⌘←, ⌥⌘→, ⌥⌘↓) or show one part alone (⇧⌘Return).
- **The browser on the iPhone and the iPad.** An agent's shells and pages are listed under it. Its page is shown live and used by touch, with the keyboard, the address bar, Show As, zoom and new tabs.
- **The iPad** has a layout of its own: on its side, the page beside the agent.
- **Settings > Agents** shows what AgentTerm tells each agent, and lets you change it. **Settings > Shell** sets which shell a new session starts, what is run in it first, and how the terminals look.

## Changed

- AgentTerm no longer writes its MCP server into the settings of Claude Code, Codex, Copilot CLI and Antigravity. Each session it starts is given the server for that session only, as it is given its hooks. What earlier versions put in those settings is taken out once, with each agent's own `mcp remove`; an agent that refuses is named in the banner, with the command to run yourself.
- The switches "Agents can open shells you see", "Agents run their commands in shells you see" and "Agents' shells say when a command ends" are gone: the server is always given, and what an agent is told is changed in Settings > Agents.
- The two-panel diff shows a diff whole, where it stopped at 2,500 rows; on the Mac it scrolls a diff of 20,000 lines without a stall.
- Worktrees no longer run a setup command when made.
- The Mac app is larger: Chromium comes with it.

## Fixed

- A long message from the iPhone, or an instruction from a notification, reaches the agent whole and is sent, rather than left as a new line in its input.
- A Codex session whose hooks are not trusted says why its state is not known, and what to do.
- On the iPhone, a session's note can be read by touching its mark.
